# Asjad Pathan — Futuristic Developer Portfolio

Personal portfolio for Asjad Afzal Pathan, a B.Tech Computer Science student focused on full-stack development and exploring applied AI.

Live site: https://asjadpathan31.github.io/portfolio/

## Design & implementation
- Dark, futuristic visual system with electric cyan and violet accents
- Custom CSS/SVG-inspired interface artwork for featured projects
- Canvas-based animated network background
- CSS orbital core, glow, signal and motion effects
- Responsive navigation and layouts
- Scroll-triggered reveals and reduced-motion support
- Semantic HTML, CSS and vanilla JavaScript

## Selected projects
- [EstateX Light](https://github.com/Asjadpathan31/EstateX-light)
- [FitTrack Pro](https://github.com/Asjadpathan31/fittrack-pro)

Project artwork is illustrative, not a screenshot or claim of a deployed production system. See each repository for source code and setup details.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.
