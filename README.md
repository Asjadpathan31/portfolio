# Asjad Pathan — Developer Portfolio

Personal portfolio for Asjad Afzal Pathan, a Computer Science student focused on full-stack development and practical AI exploration.

Live site: https://asjadpathan31.github.io/portfolio/

## Built with
- Semantic HTML, responsive CSS and vanilla JavaScript
- Editorial layouts and original CSS project artwork
- Intersection Observer reveal interactions
- Mobile navigation and reduced-motion support

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.
