# Asjad Pathan — Portfolio

A fully rebuilt, responsive portfolio for a B.Tech CSE student focused on full-stack development and applied AI exploration.

- Dark obsidian / copper art direction
- Interactive Three.js sculpture, GSAP motion and Lenis smooth scrolling via CDN
- Responsive project, about, toolkit and contact sections
- Static GitHub Pages deployment; no build step or paid domain
- Reduced-motion support

Featured work: [EstateX Light](https://github.com/Asjadpathan31/EstateX-light) · [FitTrack Pro](https://github.com/Asjadpathan31/fittrack-pro)

Run locally: `python -m http.server 8000` and open `http://localhost:8000`.
