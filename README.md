## Run locally

No build step is required.

```bash
git clone https://github.com/Asjadpathan31/portfolio.git
cd portfolio
```

Open `index.html` in a browser, or use a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
