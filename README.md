# Asjad Pathan — Developer Portfolio

A personal portfolio for Asjad Afzal Pathan, a B.Tech Computer Science student at GH Raisoni International Skill Tech University, Pune (graduating 2028). Focus: full-stack development and applied AI exploration.

**Live:** https://asjadpathan31.github.io/portfolio/

## Direction
- Warm editorial art direction: paper, charcoal and vermilion
- Large expressive typography, asymmetric portrait-led hero and custom project artwork
- Responsive layouts and accessible mobile navigation
- Lightweight HTML, CSS and vanilla JavaScript; no build step
- Reduced-motion support

## Selected work
- [EstateX Light](https://github.com/Asjadpathan31/EstateX-light) — React + Flask property discovery application
- [FitTrack Pro](https://github.com/Asjadpathan31/fittrack-pro) — fitness tracking application

Project graphics are original illustrative compositions, not screenshots of the live applications. See repositories for source and implementation details.

## Run locally
Open `index.html` or run `python -m http.server 8000` and visit http://localhost:8000.
